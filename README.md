# Dify 电商助手

## 简介
这是一个基于Dify构建的智能电商助手，旨在帮助商家自动处理客户咨询、商品推荐和订单查询等常见问题。

## 功能特点
- **智能问答**：自动回答关于跨境电商常见问题。
- **意图识别**：如果识别到用户问的是关于跨境电商的问题，则调用知识库来回答

## 安装与使用
1.  登录你的Dify实例（cloud.dify.ai 或自建）。
2.  进入“工作室”或“应用”页面，点击“从DSL导入”[reference:9]。
3.  上传本仓库中的 `ecommerce-assistant.yml` 文件。
4.  按提示配置必要的API密钥（如模型供应商的密钥）。

## 配置要求
- Dify版本：v0.6.0 或更高
- 模型供应商：OpenAI / Anthropic / 其他
